Процедура в PostgreSQL - это объект БД, принимающий аргументы, предназначенный для выполнения последовательности
действий с возможностью управления транзакциями, который обычно не возвращает результирующее значение.

Главные отличия функций и процедур в PostgreSQL:
1. Функции вызываются внутри запросов, а процедуры вызываются только при помощи команды "CALL".
2. Процедуры могут управлять транзакциями, а функции - нет.
3. Функции обычно используются для вычисления и получения какого-то результата, а процедуры - для изменения состояния
БД.

Процедуры создаются при помощи команды "CREATE PROCEDURE". Внутри процедуры:
1. Команда "CALL" вызывает процедуру.
2. Части процедурного блока "BEGIN" и "END" задают границы блока кода.
3. Часть команды "LANGUAGE" позволяет указывать интерпретатор для выполнения тела процедуры.
4. Символы "$$" позволяют выделить тело процедуры как единый строковый литерал, избавляя от необходимости экранировать
обычные одинарные кавычки внутри кода процедуры.
5. Модификатор аргумента "OUT" позволяет помечать параметры процедуры как возвращаемые значения.
6. Команда "DROP PROCEDURE" удаляет процедуру.

Примеры процедуры в PostgreSQL:

CREATE PROCEDURE add_user(new_id INTEGER, new_username VARCHAR(50), new_email VARCHAR(50), new_age INTEGER)
	LANGUAGE plpgsql AS $$
	BEGIN
		INSERT INTO users (id, username, email, age) VALUES (new_id, new_username, new_email, new_age);
	END;
	$$;

CALL add_user (5, 'John', 'John123@example.ru', 40);
