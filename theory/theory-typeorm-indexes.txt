Декоратор "@Index()" из TypeORM позволяет создавать индексы, при этом в параметрах декоратора можно указывать имя
индекса.

Индексы, добавляемые миграцией, желательно делать с модификатором "CONCURRENTLY" - этот модификатор заставляет
PostgreSQL строить индекс в фоне, не блокируя таблицу, чтобы операции записи и чтения продолжали работать. Нужно
помнить, что нельзя использовать модификатор "CONCURRENTLY" в транзакции, соответственно, нужно отключать транзакции.

Для создания составного индекса нужно использовать декоратор "@Index()" на уровне сущности.

Для создания частичного индекса в декораторе "@Index()" нужно использовать опцию "where".

Для создания GiST индекса в декораторе "@Index()" нужно использовать опцию "spatial", но это частный случай для
spatial-колонок (PostGIS).
