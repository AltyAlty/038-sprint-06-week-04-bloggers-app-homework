Настройка пакетного менеджера в WebStorm:
1. Перейти Settings -> Languages & Frameworks -> JavaScript Runtime.
2. Package manager - pnpm.

/*--------------------------------------------------------------------------------------------------------------------*/

Настройка Prettier в WebStorm:
1. Перейти Settings -> Languages & Frameworks -> JavaScript -> Prettier.
2. Manual Prettier Configuration - ON.
3. Run on 'Reformat Code' action - ON.
4. Apply Prettier to files outside the prettier dependency scope - OFF.
5. Run for files - добавить шаблон "json".
6. Run on save - ON.

/*--------------------------------------------------------------------------------------------------------------------*/

Настройка ESLint в WebStorm:
1. Перейти Settings -> Languages & Frameworks -> JavaScript -> Code Quality Tools -> ESLint.
2. Automatic ESLint configuration - ON.
3. Run eslint --fix on save - ON.

/*--------------------------------------------------------------------------------------------------------------------*/

Настройка запуска тестов через Jest в WebStorm:
1. Сверху слева три вертикальные точки -> Edit...
2. Удалить все конфигурации для Jest.
3. Перейти Edit configuration templates ...
4. Configuration file -> указать путь к файлу "jest.config.ts".
5. Node options -> указать "--experimental-vm-modules --disable-warning=ExperimentalWarning"
6. Jest package -> указать путь к пакету Jest.
7. Working directory -> указать путь к папке проекта.
8. Jest options -> указать "--runInBand".
9. Environment variables -> указать "NODE_ENV=test".
