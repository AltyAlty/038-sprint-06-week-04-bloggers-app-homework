В TypeORM миграционный файл состоит из одного класса с двумя методами:
1. "up()" - используется для применения миграции.
2. "down()" - используется для отката миграции.

Для работы с миграциями TypeORM создает отдельную таблицу "migrations".

Организация работы с миграциями на TypeORM:
1. Создать папку "migrations", которая будет содержать миграционные файлы.

2. При конфигурации метода "forRootAsync()" класса "TypeOrmModule" отключить опцию "synchronize".

3. При конфигурации метода "forRootAsync()" класса "TypeOrmModule" использовать опцию "migrations", в которой указать
массив с путем к папке "migrations".

4. Создать конфигурационный файл "typeorm.config.ts" для TypeORM, который потребуется скриптам, работающим с миграциями,
так как они будут работать вне NestJS.

5. В файл "package.json" добавить следующие скрипты (если транспиляция файлов ".ts" согласно файлу "tsconfig.json"
происходит в ESM-модули, то вместо "typeorm-ts-node-commonjs" нужно использовать "typeorm-ts-node-esm".):

5.1 Генерация миграции:
"migration:generate": "cross-env NODE_ENV=development typeorm-ts-node-commonjs migration:generate -d ./src/migrations/config/typeorm.config.ts"

Запуск:
pnpm run migration:generate ./src/migrations/migration_description

5.2 Применение всех миграций, которые еще не были приняты, в порядке их отметок времени:
"migration:run": "cross-env NODE_ENV=development typeorm-ts-node-commonjs migration:run -d ./src/migrations/config/typeorm.config.ts"

Запуск:
pnpm run migration:run

5.3 Откат последней примененной миграции:
"migration:revert": "cross-env NODE_ENV=development typeorm-ts-node-commonjs migration:revert -d ./src/migrations/config/typeorm.config.ts"

Запуск:
pnpm run migration:revert

5.4 Создание пустого файла миграции:
"migration:create": "cross-env NODE_ENV=development typeorm-ts-node-commonjs migration:create ./src/migrations/"

Запуск:
pnpm run migration:create ./src/migrations/migration_description
